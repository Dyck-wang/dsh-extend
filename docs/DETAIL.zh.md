# 功能扩展（dsh-extend）

为 DSH 桌面端补上三个日常操作：**清理历史会话**、**一键重启**、**生成 AGENTS.md**，外加**窗口位置记忆**。

## 历史会话清理 `/clean`

- 在对话里输入 `/clean`：打开**勾选面板**。面板第一项是**已归档会话**，其后是按时间（30 / 90 天）、全部会话、空会话。
  每条显示标题、项目、最后活动时间与体积；逐条勾选/取消后，只删除勾选中的会话。「全部会话」默认不勾选，
  想全删时在面板里点「全选」即可。
- 使用中的会话（包括你正在对话的这个）会出现在列表里，但不可勾选；子代理会话会跟随父会话一起删除。
- 面板支持搜索、全选、清空；底部需要勾选「我已了解删除后不可恢复」才会启用删除按钮。删除完成后面板
  直接显示「已删除 N 个，释放 X」以及失败原因。
- 也可以直接使用命令行形式：

  ```text
  /clean                         # 带序号的清单（默认前 40 条）
  /clean list --limit 0          # 全部
  /clean 3 5 7                   # 删除清单里第 3、5、7 个
  /clean --older-than 30d        # 预览
  /clean --older-than 30d --yes  # 执行
  /clean --empty --yes           # 删除“没有任何用户消息”的会话
  /clean --all --yes             # 删除全部非活跃会话
  ```

- 删除是**永久**的，不进入回收站；每次删除会写一条审计记录到 `<DSH_HOME>/.dsh-extend/audit.log`。
- 删除前会先落盘、再从项目记录中摘除并通知界面，侧栏即时刷新。

## 一键重启 `/reboot`

- 输入 `/reboot` 直接重启（默认等同 `--yes`，不再弹出确认框），窗口在 1-3 秒后回来。
- 自检：`/reboot --check`；有任务运行时强制重启：`/reboot --force`；`/reboot --yes` 仍兼容。
- 重启会中断正在运行的回合，并丢失输入框里未发送的草稿。

## 生成 AGENTS.md `/init`

- 在仓库里输入 `/init`（可跟一句补充说明），插件先扫描仓库（目录树、README、package.json、配置、现有 AGENTS.md），
  再把带绝对路径的任务消息交给当前智能体；智能体会按需询问后写入仓库根目录的 `AGENTS.md`。
- 行为与独立的 `dsh-init-plugin` 一致；合并后不要同时启用那个插件（命令重名会导致注册失败）。

## 系统提示词管理 `/prompt`

- 输入 `/prompt` 打开管理面板：按段列出**已组装提示词**（DSH 内核、桌面端与已安装插件贡献的结果），可编辑、禁用、还原；
  “自定义”页可新增/编辑/删除追加在末尾的提示词。
- 已组装段只做覆盖（不改安装文件），“还原全部默认”即回到当前组合的默认结果；每段也可单独还原。
- 修改在下一轮模型请求生效；Agent 预设使用固定完整提示词时（`complete` 段）不参与覆盖。
- 状态保存在 `<DSH_HOME>/.dsh-extend/prompts.json`，写入前保留 `.bak`。

## 窗口位置记忆

- 正常退出桌面端时，插件会记住主窗口的位置、大小与最大化状态，下次启动自动恢复。
- `/reboot` 重启前也会保存一次；强杀进程时沿用上一次保存的状态。
- 保存的位置若落在已断开的显示器上，会自动夹回当前屏幕范围。

## 安装

在 **插件 → 添加插件** 中粘贴本包的绝对路径（目录或 `.tgz` 均可），安装后选择**立即启用**。
首次安装后插件还没有被加载，用包内 `tools\restart-dsh.cmd` 重启一次即可；之后就可以直接用 `/reboot`。
